# PRD Generator

## Purpose
Generate Product Requirements Documents automatically from user input.

## Input
```
Project Description: Build a Telegram chatbot for a gynecology clinic in Kabul
```

## Output Structure
```markdown
# Product Requirements Document

## 1. Overview
- Product Name
- Vision
- Target Users

## 2. Problem Statement
- Current Challenges
- Market Gap

## 3. Solution
- Features
- User Flows

## 4. Requirements
- Functional Requirements
- Non-Functional Requirements

## 5. Success Metrics
- KPIs
- Milestones
```

## Implementation
- Use OpenAI GPT-4 or Claude API
- Prompt engineering templates
- Output validation
